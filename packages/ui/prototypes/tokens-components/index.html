Tokens and components

The values and parts the new admin UI is built from, in the Hanko identity: ink and paper, one vermilion seal, a condensed heavy grotesque. Everything on this sheet reads its values from tokens.css.

The seal

From 20 px up the seal holds 黒白. Below that it switches to a second drawing on a 16 px grid: 白 alone, cut from the square, so the ground is the black and the character is the white.

Icons

Twelve, drawn on a 16 px grid as solid shapes with square ends. An icon is only ever a control's handle; anything that needs explaining is a word.
