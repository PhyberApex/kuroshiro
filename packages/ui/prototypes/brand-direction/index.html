Screens in Order

    On the Device

    The fallback screens and the admin UI are the same object: same face, same two values, same mark. Nothing has to be translated for the panel.

    Honest risk

    Patterns can vibrate on low-density displays, and with no greys and no accent the hierarchy rests entirely on size, inversion and rule weight. An all-caps pixel face is tiring in long forms, so the Plugin editor and settings pages would lean on the grotesque.
